## 本项目的具体改动

1. 对话页「＋」打开助手库，支持分类筛选、搜索、完整提示词预览、添加状态和进入对话。
2. 自定义新建和「以此为模板新建」均进入同一个编辑器，设置基本信息、描述、分组、模型、提示词及模型参数。
3. 新助手使用独立 ID、默认话题；默认模型从全局设置继承。添加模板不改已有助手；复制助手不复制聊天记录。
4. 编辑先保存在本地草稿，保存后再更新服务器。取消修改需确认，失败保留草稿，提交期间锁定按钮，空白名称校验。
5. 助手列表支持描述搜索、分组筛选、置顶。对话头部和侧栏编辑入口共用编辑器。
6. 助手库模板与初始种子数据使用同一配置文件。旧版未改动的内置助手仅补充分组与模板 ID，不改提示词、模型和聊天记录。
7. 初始化标记避免用户删光助手后重启又自动补回所有模板；空状态仍能进入助手库。
8. 助手/话题快速切换时，过期网络响应不会覆盖当前选中项。

## 明确的实现边界

- 助手库使用本项目已有的 15 个本地模板，不是 Cherry 官方/社区目录的完整镜像，界面对此标明。
- 保留 V1 风格的侧栏，参考 V2 的库/预览/编辑交互；不是逐像素复制。
- 当前使用简单字符串分组，不引入 Cherry 的独立 Group 数据表、归档与回收站体系。
- 本项目统一采用显式保存草稿，不照搬原版部分编辑流程的自动保存。
- 不增加无效的知识库/MCP/浏览器工具入口；助手角色提示词不等于 CLI 执行权限。
- 模型参数的支持情况仍由所选服务商决定。

## 验证

- `npm test`：现有单元测试、协议测试与新增助手接口测试。
- `npm run test:assistants`：9 项，独立临时数据目录，覆盖模板、名称校验、默认模型、默认话题、编辑、复制、持久化、删除隔离。
- `npm run test:assistant-ui`：18 项，jsdom 驱动实际 React 页面，覆盖库入口、搜索、预览、模板新建、参数页、创建后切换、编辑保存、取消、空白新建与校验。
- `npm run test:smoke`：86 项，原有四模块回归。
- `npm run build`：正式前端产物。

交互测试不是浏览器像素/截图测试；jsdom 无布局引擎产生的 textarea NaN 高度警告单独排除，其他运行错误仍报失败。

## 更新与数据保留

关闭旧服务，备份原 `data` 目录，将新版压缩包内 `agent-studio` 的内容覆盖到原项目目录，保留 `data`，运行 `start.bat` 后刷新浏览器。
